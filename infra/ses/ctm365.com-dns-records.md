# DNS records for sending alert email from ctm365.com (Amazon SES, us-west-2)

Add these in Bluehost: Domains > ctm365.com > DNS. In Bluehost's **Host** field, enter only the part
before `.ctm365.com` (shown below). They don't change your Microsoft 365 email or the existing SPF record.

## DKIM (proves the email really comes from ctm365.com)

| Type  | Host                                          | Points to                                              |
|-------|-----------------------------------------------|--------------------------------------------------------|
| CNAME | `m52rtsrulne4pobr2q5jujg4az7vh6hj._domainkey` | `m52rtsrulne4pobr2q5jujg4az7vh6hj.dkim.amazonses.com`  |
| CNAME | `oi6xynojwezvakr27eljco77cm6b7we3._domainkey` | `oi6xynojwezvakr27eljco77cm6b7we3.dkim.amazonses.com`  |
| CNAME | `qve5qrybfvzqk7cmxa7oqjwsen54zctw._domainkey` | `qve5qrybfvzqk7cmxa7oqjwsen54zctw.dkim.amazonses.com`  |

## Bounce address (mail.ctm365.com, so the root SPF record stays as it is)

| Type | Host   | Value                                   | Priority |
|------|--------|-----------------------------------------|----------|
| MX   | `mail` | `feedback-smtp.us-west-2.amazonses.com` | 10       |
| TXT  | `mail` | `v=spf1 include:amazonses.com ~all`     |          |

SES checks these automatically, usually within an hour of adding them (DNS can take up to 72 hours).
Status: `aws sesv2 get-email-identity --region us-west-2 --email-identity ctm365.com`
